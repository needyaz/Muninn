Muninn Privacy Policy

Effective date: November 6, 2026

Overview

Muninn is a clipboard manager for macOS. It is open source, and this policy explains what data it accesses and how it is handled.

Data collection

Muninn does not collect, transmit, or share any personal data. It is sandboxed with all network access turned off, so it cannot send anything off your Mac.

What Muninn stores

Muninn reads the system clipboard to keep a history of what you copy (text, images, PDFs, files, colors, and the app each item came from) and your saved snippets. It also keeps simple usage counts (copies per content type, per source app and per day) for its Stats screen, and your preferences. All of this is stored on your Mac in the app's folder in Application Support. That folder is readable only by your user account and is excluded from backups. It is not encrypted, so other programs running as you could read it.

On-device processing

If you leave them on, Muninn runs text recognition on images, barcode detection and PDF text extraction using Apple's frameworks, entirely on your Mac. The results are stored with the item so they can be searched. Muninn also watches the screenshot folder you choose, to add screenshots to your history.

Sensitive content

Items that password managers mark as concealed are skipped by default. You can instead choose to record only a placeholder (the value is never stored) or to record them normally. Items marked transient are never recorded. You can also exclude apps and content types, or pause recording.

Exports and Shortcuts

You can export your data to a file you choose; the file is not encrypted and leaves out sensitive items. Muninn also offers actions to the Shortcuts app that return your non-sensitive history, so any shortcut you run can read it.

Analytics and tracking

Muninn does not use any analytics, tracking, crash reporting, or telemetry. The only third-party code in the app is an open source keyboard-shortcut library that runs locally.

Contact
