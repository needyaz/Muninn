# Contributing

Muninn is open source so you can read it, build it, and fork it. It is **not accepting outside code contributions**: pull requests
will be closed without review.

That's deliberate. Muninn is licensed under the GPLv3, and keeping all the code written by one author keeps the option of
distributing it through the Mac App Store, whose terms the GPL doesn't allow for code the distributor doesn't own.

## What is welcome

- **Bug reports and feature ideas:** [open an issue](https://github.com/needyaz/Muninn/issues). Include your macOS version and what
  you copied from (the app and the kind of content), but never paste real passwords or private clipboard contents.
- **Security reports:** see [SECURITY.md](SECURITY.md); don't file those as public issues.
- **Forks:** the GPLv3 lets you fork and change Muninn freely, as long as your fork stays under the GPLv3.

## If you're building it yourself

See the [README](README.md) for build steps and the project layout. `make test` runs the tests.
